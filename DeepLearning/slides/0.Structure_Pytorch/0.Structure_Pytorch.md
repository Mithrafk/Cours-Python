### 2. Gradient
**La structure tensor intègre aussi un champ grad (gradient)**
`backward()` : calculer la valeur du gradient
- variables de base sur lesquels on a activé le gradient
- la variable "fonction" sur laquelle on a pas activé le gradient (et qui depend des n autres)
- backward permet de calculer la dérivée partielle de notre fonction p/r aux variables avec `requires_grade=True`

$=>$ Le résultat de z p/r à a se retrouve dans `a.grad.item()`  

**erreur fréquentes avec gradient :**  
si on active le gradient, on a dans la variable les données `b.data` et la valeur du gradient `b.grad.data`
