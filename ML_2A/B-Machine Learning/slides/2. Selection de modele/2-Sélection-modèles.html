2Classification : matrice de confusion, précision, rappel, F1

La matrice de confusion compte ce qui est bien classé ou pas et permet de comprendre les confusions : cas binaire (2×2), ou données de chiffres USPS où la diagonale domine et où l’on repère des paires souvent confondues (dans tes notes : 4 et 9).

Détection d’un évènement (contre le bruit de fond)

Métriques dédiées à une classe particulière :

Précision = TP / (TP + FP) = détections pertinentes / détections Rappel = TP / (TP + FN) = détections pertinentes / taille de la classe (couverture) F1 = 2 · précision · rappel / (précision + rappel) (moyenne harmonique)
Prédit positifPrédit négatif
Vraiment positifTP (vrai positif)FN (faux négatif : détection manquée)
Vraiment négatifFP (faux positif : fausse alerte)TN (vrai négatif)

Pour agréger sur toutes les classes (dans les cas pertinents) : macro-moyenne = moyenne des scores de chaque classe (non pondérée) ; micro-moyenne = agrégation au niveau des échantillons (donc pondération des classes par leur effectif).

Macro ou micro ?

Une matrice de confusion à 3 classes très déséquilibrées (lignes = vraie classe, colonnes = classe prédite). Modifie les nombres et compare la F1 macro et la F1 micro.

Tes notesTes notes définissent la précision comme le « taux de faux positifs » et le rappel comme le « taux de faux négatifs » : c’est l’idée, mais pas la formule. La précision est la part de vraies alertes parmi les alertes : TP/(TP+FP), donc elle baisse quand il y a beaucoup de faux positifs. Le rappel est la part des vrais évènements détectés : TP/(TP+FN), donc il baisse quand il y a beaucoup de faux négatifs. Le « taux de faux positifs » (FPR = FP/(FP+TN)) est une autre grandeur, celle de l’axe horizontal de la courbe ROC. Tu as bien noté qu’on les calcule sur une seule classe. Complément : la diapo écrit « précision (sensibilité) » ; dans l’usage courant, la sensibilité est plutôt un autre nom du rappel.

3Classification déséquilibrée, courbe ROC et AUC

Exemple : la fraude à la carte bleue, environ 0,3 pour mille des transactions. Impact sur les modèles : le modèle apprend à prédire que tout est OK. Impact sur les métriques : la métrique annonce 99,07 % de bonne classification, alors que le modèle ne détecte rien.

ROC : un classifieur = un ensemble de classifieurs biaisés

En faisant varier le seuil de décision (le biais b d’un classifieur linéaire), on obtient toute une famille de classifieurs. La courbe ROC (receiver operating characteristic) trace, pour chaque seuil, le taux de vrais positifs (TPR = rappel) en fonction du taux de faux positifs (FPR). Elle mesure la capacité à détecter les évènements sans ajouter de bruit quand on fait varier la sensibilité. On peut faire la même chose en précision / rappel.

Indicateurs multiples = difficile à manipuler et à expliquer : précision + rappel ⇒ F1 ; ROC ⇒ AUC (Area Under the Curve) : 0,5 pour un classifieur aléatoire, 1 pour un classifieur parfait.

4Processus d’évaluation

  • Évaluer sur les données d’apprentissage = tricherie (surestimation). Évaluer sur des données vierges = OK. Problème de la répartition apprentissage / test : la validation croisée (K itérations, K modèles, K performances).
  • Deux implémentations : (1) séparation train/test (itérative pour la validation croisée) + apprentissage + calcul des scores ; (2) calcul direct des scores de validation croisée (la boucle, la division, l’apprentissage et la mesure sont cachés dans la méthode).

L’évaluation est la clé de la sélection(1) Phase critique de dialogue avec le client : identifier les attentes, montrer le niveau de performance. (2) Outil critique pour la sélection de modèles. (3) Significativité : quand un modèle est-il vraiment meilleur qu’un autre ? Très peu de données (< 50) ⇒ statistiques avancées. Beaucoup de données (> 10 000, ex. MNIST) ⇒ presque toujours significatif. Intermédiaire ⇒ test de Student sur des validations croisées. Étape coûteuse mais indispensable, parallélisable (n_jobs).

Deux modèles : la différence est-elle significative ?

Un arbre de profondeur A contre un arbre de profondeur B, sur les mêmes découpes de validation croisée. Un test t apparié sur les scores par partie donne une p-value. Prédis : la p-value baisse-t-elle quand on ajoute des données ?

Tes notes« La validation croisée permet de comparer 2 modèles et de donner des p-values sur l’écart. » Oui. Deux précisions : (1) les K modèles de la validation croisée ne sont pas « compilés en 1 » : chacun est évalué sur sa partie de test, et on moyenne les K scores ; le modèle final se réentraîne ensuite sur toutes les données. (2) Complément : les K scores ne sont pas indépendants (les jeux d’apprentissage se recouvrent), donc le test t classique est optimiste ; des corrections existent (Nadeau et Bengio).

Jusqu’où aller dans la séparation des données ?

Optimiser les paramètres avec les scores de validation croisée puis publier ces mêmes scores = surestimation des performances. Deux architectures multi-boucles : une boucle externe qui estime la performance de généralisation (on garde un pli de test), et une boucle interne qui règle les paramètres sur le reste (validation croisée dans l’apprentissage) ; ou le découpage simple apprentissage / validation / test (section 11).

6Sélection de variables : fléau de la dimensionnalité

Un individu xi ∈ ℝd ; une caractéristique Xj. Croyance naïve : plus d est grand, plus j’ai de chances de bien répondre à la tâche. Contre-exemple : régression aux moindres carrés avec d > n : XᵀX · w = Xᵀy. La matrice XᵀX est d × d mais de rang n seulement : on n’a que n équations indépendantes pour d inconnues, problème mal posé.

Fléau de la dimensionnalité (curse of dimensionality) : sur un problème facile (classes séparées), on ajoute des dimensions de bruit. La matrice de distances entre points perd sa structure en blocs : la distance euclidienne est très sensible à la dimension ; les points tendent à se placer sur une hypersphère (ils deviennent équidistants). Un classifieur de base voit son exactitude d’apprentissage monter et celle de test descendre : c’est du sur-apprentissage.

Ajoute des colonnes de bruit

Deux dimensions utiles et 67 exemples, comme sur la diapo 17/30. Prédis : que devient l’exactitude de test du plus proche voisin quand on ajoute 20 colonnes de bruit ? Et la matrice de distances ?

Tes notes« Imshow (heatmap) donne de manière visuelle les distances entre des points ; permet de discerner le bruit à l’œil humain, mais la machine a du mal → penser à nettoyer ses données. » C’est ce que montre la matrice de distances ci-dessus : à l’œil, les blocs disparaissent avec le bruit ; pour la machine, tous les points deviennent pareillement éloignés. « Rajouter du bruit (des colonnes) pousse au sur-apprentissage » : modèle très complexe en apprentissage, faible en test.

7Bonne ou mauvaise variable ?

Comment savoir si Xj est une variable d’intérêt ? Corrélation XjᵀY : mais elle ignore les approches non linéaires (avec un SVM on peut construire une variable idéale pour estimer Y de corrélation nulle), et les variables intéressantes mais corrélées entre elles (XjᵀY et XkᵀY élevées avec Xj ≈ Xk : redondance). Autres questions : combien de variables garder ? Certaines variables ont-elles un intérêt combinées à d’autres ?

Trois grandes familles : (1) choisir les caractéristiques pertinentes et éliminer les autres : avec un expert, en analysant les paramètres des classifieurs (introspection), en testant des combinaisons + scoring (extrospection) ; (2) utiliser l’ACP pour trouver les meilleures combinaisons ; (3) apprendre à éliminer les variables pendant l’apprentissage (régularisation).

  • (0) Corrélations avec la cible : parfois (souvent) les stratégies les plus naïves méritent d’être testées.
  • (1) Poids d’un classifieur linéaire : f(x) = Σ wj xj, wj ≈ importance de Xj (SVM linéaire, régression logistique, ridge classification…). Bonne nouvelle : les poids des variables importantes sont plus hauts. Mauvaise nouvelle : les poids des autres sont eux aussi assez importants.
  • Importance dans les forêts : les méthodes d’ensemble sont moins sensibles à la dimension (si leurs hypothèses sont assez faibles, une forme de régularisation) et calculent l’importance : nombre de fois où la variable est utilisée, nombre de fois où elle est à la racine, où elle détermine les feuilles, pondération par l’utilité de l’arbre… Dans tes notes : la hauteur dans l’arbre (haut = très discriminant).

Corrélations, poids et effet d’échelle

n = 67 exemples, d = 22 variables dont 2 informatives (en vert). Compare le classement par corrélation et par poids d’un modèle linéaire. Puis change les échelles des variables.

Tes notesTes deux mises en garde sont justes : (1) effet d’échelle : un poids dépend de l’unité de la variable (multiplie une variable par 100, son poids est divisé par 100), donc il faut standardiser (moyenne 0, écart-type 1) avant de comparer les wj ; (2) effet de masquage : deux variables corrélées se partagent le poids, chacune paraît moins importante. Tu peux le voir en cochant la copie de la variable 0 ci-dessus.

8Sélection itérative de caractéristiques

Approches gloutonnes, mais très chères.

Élimination récursive (Recursive Backward Elimination) 1. S = {X₁,…,X_d} 2. Faire d fois : pour tous les S_i = S \ X_i : p_i = perf(S_i) (taux en test, validation croisée…) ; conserver S = meilleur S_i Sélection ascendante (Forward selection) 1. S = ∅ 2. Faire d fois : pour tous les S_i = S + X_i : p_i = perf(S_i) ; conserver S = meilleur S_i

Coût : d itérations × (d − 1) tests (avec d décroissant pour le backward, croissant pour le forward) × un test = un apprentissage + évaluation, ou nCV apprentissages + évaluations. Le forward est « un peu moins cher… mais pourquoi ? » : il faut réfléchir à la forme de la courbe de performance, d’où la notion d’early stopping : la performance monte, atteint un maximum puis stagne ou baisse ; si l’optimum est atteint avec peu de variables, le forward s’arrête très tôt, alors que le backward doit descendre presque jusqu’à la fin.

Backward contre forward, avec le coût

Score = R² en validation croisée (5 plis) d’un classifieur linéaire (moindres carrés sur y = ±1). Les deux méthodes sont exécutées pour de vrai ; l’arrêt prématuré s’applique quand le score ne progresse plus (de plus de 0,005) depuis 3 étapes.

Tes notes« Recursive Backward Elimination : on retire la moins bonne colonne, puis on recommence ; la performance atteint un maximum (on a enlevé le bruit) ; si on continue, on enlève des colonnes qui contiennent de l’information. » C’est exactement la forme de courbe ci-dessus. Précision : la version de la diapo teste toutes les suppressions possibles à chaque étape (coûteux) ; la version « à poids » (on retire la variable au plus petit |w|) est plus rapide mais dépend de l’échelle des variables.

9ACP (PCA) : analyse en composantes principales

Idée : trouver la combinaison d’axes qui explique au mieux la variance des données ; la valeur propre donne la force de l’explication. Pour d = 22 : 22 valeurs propres et 22 vecteurs propres, mais peu de valeurs significatives (la courbe des valeurs propres décroît). Les axes sont orthogonaux, même en 22 dimensions. Question de la diapo : est-ce de la sélection ou de la construction de caractéristiques ? Réponse : de la construction (chaque composante est une combinaison linéaire de toutes les variables), qui permet ensuite de réduire la dimension.

« Un algorithme à tout faire » : variantes pour les réseaux de capteurs (combinaison linéaire de sources), visualisation (Iris en 4D ; chiffres en 256 dimensions projetés en 2D).

Variance n’est pas information

Mêmes 22 variables : 2 informatives, 20 de bruit. Prédis : quand le signal est faible, les 2 premières composantes séparent-elles les classes ? Augmente la force du signal.

Tes notes(1) « Méthode du coude pour choisir le nombre de valeurs propres à garder » : oui, on regarde où la courbe des valeurs propres (ou de la variance cumulée) cesse de décroître fortement. (2) Les valeurs propres sont attachées aux axes (composantes), pas aux variables d’origine. (3) « Les axes à valeur propre forte sont souvent reconnus comme peu bruités » : c’est une hypothèse, vraie seulement si le signal domine la variance. Le laboratoire montre le cas contraire : l’ACP est non supervisée, elle ignore les étiquettes. (4) Pour tes remarques sur le graphique des chiffres (0 en haut, 1 en bas ; 3, 9, 8 à droite, 1, 4, 7 à gauche) : chaque axe est une combinaison de pixels, et la position d’une classe sur l’axe dit quels motifs de pixels la distinguent.

10Régularisation : apprendre les variables utiles

Moindres carrés : L = Σ_i ( Σ_j w_j x_ij − y_i )² Ridge (L2) : L = Σ_i ( Σ_j w_j x_ij − y_i )² + C ‖w‖² Lasso (L1) : L = Σ_i ( Σ_j w_j x_ij − y_i )² + C ‖w‖₁ = … + C Σ_j |w_j| Elastic net : L = Σ_i ( Σ_j w_j x_ij − y_i )² + C₁ Σ_j |w_j| + C₂ ‖w‖²

12Pièges à éviter

  • Précision ≠ accuracy (en français) ; précision = TP/(TP+FP) ; rappel = TP/(TP+FN) ; FPR = FP/(FP+TN).
  • Précision et rappel se calculent sur une classe ; pour plusieurs classes, choisir macro (non pondérée) ou micro (pondérée par les effectifs).
  • Sur des données déséquilibrées, une exactitude de 99 % peut cacher un modèle qui ne détecte rien.
  • Ne pas confondre métrique d’évaluation et coût optimisé.
  • Choisir les hyperparamètres sur le jeu de test : le test n’est plus vierge, la performance annoncée est optimiste.
  • Publier le score de validation croisée qui a servi à régler les paramètres : surestimation.
  • Comparer des poids wj de variables non standardisées.
  • Croire que l’ACP garde l’information utile : elle garde la variance.
  • Une corrélation faible n’exclut pas une variable utile (non linéaire, ou utile en combinaison).
  • Ridge affaiblit, Lasso annule ; ne pas attendre de sélection du Ridge.
  • d > n en moindres carrés : problème mal posé sans régularisation.
