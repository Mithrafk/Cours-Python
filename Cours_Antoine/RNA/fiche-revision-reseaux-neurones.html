Les réseaux de neurones artificiels

Fiche de révision construite à partir du cours d’Antoine Cornuéjols (AgroParisTech – INRAE MIA Paris-Saclay), 2026–27. Elle reprend le fil du support : réseaux à une couche → PMC → apprentissage → réseaux profonds → autres architectures et aspects pratiques.

1Introduction & réseaux à une couche

Inspiration biologiqueDiscriminant linéaireApprentissage en ligne

Le cours présente les réseaux de neurones artificiels comme des modèles inspirés, de manière lointaine, du fonctionnement neuronal. Le cerveau est présenté comme un système apprenant, robuste, tolérant aux fautes, capable de traiter des informations incomplètes et massivement parallèle. Les réseaux artificiels recherchent notamment la parallélisation des calculs, la robustesse distribuée et un emploi général.

Contrepartie : les réseaux sont difficiles à interpréter : le raisonnement et l’hypothèse produite sont souvent opaques.

Repères historiques

  • ~1870
    Golgi & Cajal
    Mise en évidence des neurones ; les synapses sont étudiées plus tard.
  • 1943
    McCulloch & Pitts
    Premier modèle du neurone formel.
  • 1949
    Hebb
    Règle d’apprentissage de couplage synaptique : les connexions entre neurones actifs ensemble sont renforcées.
  • 1958–62
    Rosenblatt : Perceptron
    Premier connexionnisme ; modèle apprenant, mais limité aux séparations linéaires.
  • 1969
    Minsky & Papert
    Analyse des limites du perceptron, notamment l’incapacité à traiter le XOR dans l’espace d’entrée initial.
  • 1982–2003
    Nouveau connexionnisme
    Hopfield (réseau bouclé), perceptrons multi-couches, reservoir computing, puis réseaux profonds et spiking neurons.

Perceptron : idée et équations

Dans un espace de dimension d, le perceptron définit une frontière linéaire (un hyperplan de dimension d−1).

Hyperplan : Σ(j=1→d) wⱼ xⱼ + w₀ = 0    |    h(x) = Σ(j=1→d) wⱼ xⱼ + w₀

Pour un nouveau point, le signe de wᵀx détermine la classe ; sur la frontière, le cours laisse le cas comme indéterminé.

wᵀx ≥ 0 → C₁     wᵀx ≤ 0 → C₂     wᵀx = 0 → indéterminé

Règle d’apprentissage du perceptron

Le cours insiste sur une règle simple : on apprend seulement en cas d’échec. Pour une classe positive mal classée, on augmente la projection wᵀxᵢ ; pour une classe négative mal classée, on la diminue.

Cas yᵢ = +1 et wᵀxᵢ < 0

w' = w + ηxᵢ → w'ᵀxᵢ > wᵀxᵢ

Cas yᵢ = −1 et wᵀxᵢ > 0

w' = w − ηxᵢ → w'ᵀxᵢ < wᵀxᵢ

Convergence : le cours donne une convergence en un nombre fini d’étapes si les exemples sont linéairement séparables, indépendamment du nombre d’exemples, de leur distribution et de la dimension.

À retenir pour l’examen : convergence sur les données d’apprentissage ≠ garantie de bonne généralisation sur de nouveaux exemples.

Limite fondamentale

Un perceptron seul ne peut apprendre que des séparatrices linéaires dans l’espace d’entrée choisi. Le XOR est l’exemple canonique du problème ; changer l’espace de représentation peut rendre la séparation possible, mais le prétraitement peut être difficile.

2Perceptron multi-couche (PMC)

Le PMC ajoute une ou plusieurs couches cachées. Le rôle central de ces couches est de transformer progressivement la représentation des données : elles construisent des variables latentes utiles à la tâche.

Idée clé : le réseau ne se contente plus de chercher une frontière linéaire sur les entrées brutes ; il apprend une nouvelle représentation dans laquelle la tâche peut devenir plus simple.

Structure

ÉlémentRôle

Poids wⱼₖParamètre de la connexion de la cellule j vers la cellule k.
Activation aₖQuantité avant application de la fonction d’activation.
Fonction gIntroduit la non-linéarité ou définit la transformation du neurone.

Sigmoïde

φ(x)=1/(1+eˣ) dans le support.

tanh

φ(x)=(eˣ−e⁻ˣ)/(eˣ+e⁻ˣ), valeurs dans [−1,1].

Fonction noyau gaussienne

Présentée dans le cours parmi les fonctions d’activation.

ReLU

Présente dans le cours pour les couches cachées ; valeurs dans [0,∞].

Pour la sigmoïde telle qu’elle est écrite sur la diapositive, le cours donne aussi g'(a)=g(a)(1−g(a)).

Choix de la sortie

TâcheCouches cachéesCouche de sortie
ClassificationSigmoïde, tanh, ReLU, …Sigmoïde pour une sortie ; softmax pour plusieurs classes / sorties interprétées comme probabilités d’appartenance.
RégressionSigmoïde, tanh, ReLU, …Fonction linéaire.

Exemple : XOR

Le cours montre qu’une architecture avec couche cachée peut réaliser le XOR. Les poids donnés sur la diapositive d’exemple sont :

W₁=1 ; W₂=−1 ; W₃=−1 ; W₄=1 ; W₅=4 ; W₆=4 ; W₇=−1 ; W₈=−1 ; W₉=−1

Le point important n’est pas de mémoriser ces neuf valeurs, mais de comprendre le changement de représentation permis par les couches cachées.

3Apprentissage et rétro-propagation

Le problème supervisé est : à partir d’un échantillon d’apprentissage et de connaissances préalables sur le type de dépendances, trouver une fonction permettant de prédire y pour une nouvelle entrée x.

Objectif de la descente de gradient

w* = argmin_w (1/m) Σ(l=1→m) [ y(xₗ,w) − u(xₗ) ]²

Dans le support, cet exemple utilise une erreur quadratique. La mise à jour générale est :

w(t) = w(t−1) − η(t) ∇E(w(t))
ModePrincipe
Hors-ligne / batchOn calcule le gradient sur l’ensemble des exemples avant la mise à jour.
En-ligne / stochastiqueOn met à jour après présentation d’un exemple.

Rétro-propagation : déroulé à connaître

1Présenter un exemple
Ordre séquentiel, aléatoire ou selon un critère.
2Passage avant
Calcul de l’état du réseau et de la sortie.
3Calcul de l’erreur
Par exemple (yₗ−uₗ)².
4Calcul des gradients
Par rétro-propagation.
5Modifier les poids
Descente selon le gradient et le pas η.
6Tester l’arrêt
Erreur, nombre de présentations, validation, etc.
7Recommencer
Retour à l’étape 1 tant que l’apprentissage continue.

Formules de rétro-propagation

Le support introduit δ, l’erreur attachée à une cellule. Pour une connexion wᵢⱼ :

∂Eˡ/∂wᵢⱼ = δⱼ zᵢ
Sortie : δₖ = ∂Eˡ/∂aₖ = (yₖˡ − ŷₖˡ) · g'(aₖ)
Couche cachée : δⱼ = g'(aⱼ) · Σₖ wⱼₖ δₖ
Lecture intuitive : l’erreur calculée en sortie est propagée vers l’arrière pour obtenir la contribution de chaque connexion au coût.

Coût et calcul

Le support indique une complexité de O(w) pour chaque passe d’apprentissage, avec w le nombre de poids. Il souligne également que l’apprentissage peut demander de nombreuses passes et plusieurs initialisations des poids.

Perceptron vs rétro-propagation / Hebb

RègleIdéeCaractéristique du cours
PerceptronCorrige les erreurs de classification.Apprentissage en ligne ; convergence si séparation linéaire.
Rétro-propagationCorrige le coût en fonction des gradients.Règle « top-down », peu plausible biologiquement selon le cours.
Hebb« Fire together, wire together ».Règle locale « bottom-up », ne minimise pas explicitement une fonction de coût ; associée à l’idée d’info-max et à une plus grande plausibilité biologique.

4Généralisation, sur-apprentissage et sortie

Sur-apprentissage et architecture

Le choix de l’architecture contrôle la performance en généralisation. Le cours distingue les régimes de sous-apprentissage, modèle adapté, puis sur-apprentissage.

Sous-apprentissage

Capacité ou architecture insuffisante pour représenter correctement la relation.

Modèle adapté

Compromis permettant une bonne performance de généralisation.

Sur-apprentissage

Le réseau s’ajuste trop aux données d’apprentissage et généralise moins bien.

Critères d’arrêt

  • Nombre d’époques fixé à l’avance.
  • Arrêt lorsque la baisse de l’erreur empirique cesse.
  • Early stopping : arrêt lorsque l’erreur sur l’ensemble de validation cesse de baisser.

La minimisation stochastique peut, en partie, aider à échapper aux minima locaux. Le cours signale aussi le problème des optima locaux.

Compromis biais–variance

Le support présente le compromis biais–variance comme une autre façon de réfléchir au lien entre capacité du modèle et généralisation : un modèle trop contraint produit du biais ; un modèle trop flexible peut produire de la variance et du sur-apprentissage.

Codage de la couche de sortie

ConfigurationCodage / interprétation
1 neuroneSortie {0,1} ou [0,1]. Le support mentionne l’erreur quadratique ou le critère entropique selon le cadre.
Plusieurs neuronesUne sortie par classe ; sortie considérée comme une probabilité d’appartenance. Le support introduit aussi les codes correcteurs d’erreurs (ECOC).

ECOC — Error-Correcting Output Codes

Plutôt que d’apprendre directement une sortie par classe, on peut apprendre plusieurs classifieurs binaires, puis décoder le vecteur obtenu vers le code de la classe la plus proche.

Principe : choisir des codes suffisamment différents entre classes, apprendre chaque bit / classifieur, puis décoder par plus proche voisin dans l’espace des codes.

5Réseaux de neurones profonds

Le cours passe ensuite aux réseaux convolutionnels et à l’apprentissage de représentations sur des volumes de données importants.

CNN : intuition

Une architecture convolutionnelle exploite des filtres locaux et des poids partagés. Dans l’exemple de reconnaissance de chiffres, les images sont traitées par une succession de convolutions, d’agrégations (pooling) puis de couches entièrement connectées.

CConvolution
Apprendre des filtres sur des zones locales de l’image.
SPooling
Réduire la résolution, par exemple en agrégeant des pixels contigus.
FFully connected
Utiliser les descripteurs appris pour prédire la classe.
Exemple du cours : 55 = (227 − 11)/4 + 1

AlexNet : avec une entrée 227×227×3, des filtres 11×11, un stride de 4 et 96 filtres, la première couche de convolution atteint 105 705 600 paramètres selon le calcul présenté dans le support.

Architectures citées

Architecture / systèmeMessage du cours
LeNet-5Architecture de référence avec convolution/activation, agrégation, puis couches complètement connectées.
AlexNetMontre qu’un réseau peu profond peut déjà comporter un très grand nombre de paramètres.
U-NetArchitecture intégralement convolutive et symétrique pour la segmentation ; la seconde partie reconstruit une carte de prédictions.
GoogleNetPrésenté comme un « mécano de réseaux de neurones ».

Des données aux représentations hiérarchiques

Le cours pose explicitement la question : comment connaître la bonne représentation ? Les couches cachées répondent en partie en apprenant progressivement des représentations hiérarchiques. Des visualisations de neurones de couches cachées sont citées dans le support.

ImageNet et besoins en données

ImageNet

>15 millions d’images haute résolution étiquetées et environ 22 000 catégories dans le support.

Constat

Les réseaux profonds peuvent nécessiter énormément d’exemples étiquetés.

Augmentation de données

Pour produire de nouveaux exemples à partir d’exemples étiquetés : bruitage, floutage, modification du contraste ou de la luminosité, rotation, dilatation, translation. Le support évoque aussi la génération par GAN, avec une mise en garde sur la difficulté pratique.

6Représentations, auto-apprentissage et régularisation

Auto-encodage

L’auto-association consiste à apprendre une représentation interne compacte : l’embedding. Le support le présente comme un apprentissage supervisé de fait, mais sans étiquette externe.

Self-supervised learning

Le cours le présente comme une forme d’apprentissage sans étiquette qui construit néanmoins une tâche supervisée artificielle. Exemple : prédire la position relative de deux sous-images ; pour les séquences, vérifier ou prédire des relations permettant d’apprendre des connaissances structurelles.

Normalisation

MéthodeIdée du support
BatchNormNormalisation liée à l’activité d’un lot ; le cours la classe parmi les couches modifiant les sorties selon l’activité des autres neurones.
L2-normNormalisation par une norme L2.
LayerNormNormalisation par exemple / couche selon la dimension considérée.

Dropout

Le support illustre le dropout comme la suppression aléatoire de certaines unités / connexions pendant l’apprentissage, ce qui modifie l’architecture effectivement utilisée pendant l’apprentissage.

Un résultat expérimental troublant

Zhang, Bengio, Hardt, Recht & Vinyals (2017) : sur CIFAR-10, l’architecture étudiée peut atteindre 100 % de précision d’apprentissage et environ 89 % en test sur les données originales. Avec des étiquettes aléatoires, elle atteint encore 100 % sur l’apprentissage, mais environ 9,8 % en test ; avec des pixels aléatoires, environ 10 % en test. Le point du cours : les réseaux profonds ont une capacité suffisante pour mémoriser des données arbitraires, ce qui rend la généralisation particulièrement intrigante.

Ce que cela interroge

  • Pourquoi les réseaux profonds généralisent-ils si bien sur des tâches structurées alors qu’ils peuvent mémoriser des ensembles arbitraires ?
  • Les hypothèses implicites du modèle et des données jouent-elles un rôle central dans la généralisation ?

7Limites, robustesse et interprétabilité

Adversarial learning

Le cours introduit les exemples adversariaux : de petites perturbations peuvent modifier la prédiction.

Explications

Les méthodes de visualisation comme Grad-CAM sont présentées comme des outils d’explication, mais l’interprétabilité reste difficile.

Annotation / captioning

Des applications d’annotation d’images et de génération de légendes sont montrées avec des cas d’erreurs.

Cas médical

Le support illustre également des applications en médecine et invite à considérer les limites des prédictions.

Message général du cours : une performance élevée ne suffit pas à expliquer pourquoi un réseau a réussi, ni à garantir qu’il exploitera les bonnes variables dans une situation nouvelle.

« Voiture dans une piscine »

L’exemple attribué à Léon Bottou sert à illustrer le risque de dépendre de corrélations ou du contexte plutôt que de la notion que l’on voulait réellement reconnaître.

8Autres architectures

Reservoir computing

Idée présentée : utiliser un réseau récurrent sans entraîner explicitement tout le réservoir et n’entraîner qu’une couche de sortie. Cela réintroduit une dynamique utile notamment pour les séries temporelles.

Spiking neural networks

Le cours cite les réseaux de neurones impulsionnels comme autre architecture, dans la continuité de l’idée d’inspiration biologique.

À retenir : le réseau de neurones artificiel du cours est surtout présenté comme une méthode d’induction supervisée très versatile, et explicitement comme pas un modèle biologique.

9Aspects pratiques des données

Le support termine par une série de questions qui dépassent l’architecture elle-même : le prétraitement des exemples peut conditionner directement ce que le réseau peut apprendre.

1. Transformer les variables

TypePropriétéTraitement cité
NominalPas de relation d’ordre ; exemples : sexe, profession.One-hot-encoding pour transformer une variable catégorielle.
OrdinalRelation d’ordre entre modalités ; exemple : petit, moyen, grand.On peut exploiter les rangs.
Numérique / continuOrdre, distance et calculs arithmétiques.Peut être discrétisé si l’algorithme l’exige.

2. Discrétisation

Le support cite notamment des intervalles de largeur égale ou des intervalles de même fréquence.

3. Bruit

Le cours distingue bruit aléatoire, bruit dépendant de la classe, bruit dépendant de la source, données fiables ou non fiables et données censurées.

4. Valeurs manquantes

De nombreux systèmes ne traitent pas directement des données incomplètes. Le support cite plusieurs stratégies : moyenne, modalité la plus fréquente, moyenne de la classe, ou imputation par une fonction de prédiction.

L’imputation par prédiction suppose des interdépendances entre variables et pose aussi la question de l’utilité réelle de la variable imputée.

5. Normalisation

Lorsque les variables ont des échelles très différentes, le support indique que cela peut fausser les régularités apprises. Il cite la centrée-réduite, les transformations dans [0,1] et la discrétisation en un même nombre de valeurs, tout en précisant que la normalisation n’est pas forcément une bonne idée dans tous les cas.

ACP, ISOMAP, t-SNE

ACP : méthode linéaire optimisant un critère quadratique ; le support souligne sa sensibilité aux points aberrants. ISOMAP cherche à préserver les propriétés de la variété sous-jacente via les voisinages et les distances. t-SNE part de probabilités conditionnelles et projette en 2D ou 3D ; le support indique une complexité quadratique en nombre d’exemples qui impose des optimisations.

7. Classes déséquilibrées

  1. Sous-échantillonner la classe majoritaire.
  2. Créer des exemples de la classe minoritaire, par exemple par bruitage.
  3. Modifier les coûts de mauvaise classification.

8. Points aberrants

Le support cite l’expertise, les contraintes d’intégrité et la détection par apprentissage, notamment One-Class SVM et le boosting.
